Engenharia de dados · Python · SQL · Power BI

3arquivos de entrada
30vendas válidas
6linhas separadas para conferência

O problema

Uma loja precisa reunir vendas de diferentes meses. Os arquivos contêm datas em formatos diferentes, nomes com espaços, duplicatas e datas inválidas.

A entrega

Uma rotina Python padroniza os dados, calcula valores e gera relatórios. Das 36 linhas recebidas, 30 são vendas válidas, 3 são cópias exatas removidas e 3 têm datas inválidas e seguem para revisão.

Aplicação em outros negócios

A mesma abordagem pode ser adaptada para arquivos de estoque, despesas e cadastros, após analisar os dados e combinar as regras.
